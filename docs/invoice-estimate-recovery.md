## 引き継ぎ

- PDF生成は `invoice/invoice` を使用する。
- Goソースを変更した場合は `cd invoice && go build -o invoice .` で更新する。
- 請求書は勘定科目 `106`、`401`、課税時は `210` を使用する。
- 見積書は会計年度・伝票・勘定科目とは関連付けない。
- 本番サーバ上の旧未コミット実装は、デプロイ確認後に整理する。
