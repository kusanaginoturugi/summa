# Work Plan

## 2026-10-01 請求書複製時の備考引き継ぎ修正

- 複製元の備考が新規請求書の備考初期値に上書きされないようにする。

## 2026-10-01 請求書一覧の操作ボタン表示調整

- 請求書一覧の操作ボタンを1行に収める。
- 請求先・件名の列幅を調整し、長い値は省略記号で表示する。
- 省略名が登録されている請求書は、一覧の請求先欄に省略名を表示する。

## 2026-10-01 請求書複製作成

- 請求書一覧から既存請求書を複製して新規作成できるようにする。
- 複製時は発行元・請求先・件名・明細・備考を引き継ぎ、請求番号・請求日・支払期限を新規用の値にする。

## 2026-07-01 勘定科目ロック解除

- 年度繰越が成功したら、勘定科目マスタの編集ロックを解除する。
- 既存本番データ向けに、一括解除できる Rake task を追加する。
- サービス単体テストと全体テストで確認する。

## 2026-07-01 科目別入力の金額ラベル改善

- 現行の符号入力仕様は維持する。
- `費用` ラベルを `入出金額` に変更し、正負の意味を tooltip で補足する。
- 全体テストで確認する。

## 2026-07-01 無効な取込ルール検出と勘定科目一覧UI調整

- 科目表に存在しない科目コードを参照する `ImportRule` をCSV取込画面で検出する。
- 無効な取込ルールを一括削除できるようにする。
- 取込時は存在しない科目・ロック中科目を指すルールを自動マッチ対象から外す。
- 勘定科目一覧の行アクションボタンのサイズを揃える。
- 全体テストで確認する。

## 2026-07-01 科目別入力の期間フィルタ

- 科目別入力に月単位の表示期間フィルタを追加する。
- 詳細画面から更新・削除した後も科目別入力へ戻る条件を維持する。
- 表示期間のUIは月だけを選ぶ形式にする。
- 貸借残高は表示期間でリセットせず、年度内の通し残高を表示する。
- 月選択の幅を短くし、フィルタ行が1行に収まりやすくする。
- controller test と全体テストで確認する。

## 2026-07-30 請求書備考欄の入力改善

- 請求書フォームの備考欄を請求情報セクションへ移動する。
- 備考欄には振込先・支払条件などを入力できるよう placeholder を追加する。
- 新規請求書作成時は前月請求書の備考を初期値として引き継ぐ。
- controller test と全体テストで確認する。

## 2026-09-17 見積書複製作成と数値表示改善

- 見積書一覧から既存見積を複製して新規作成できるようにする。
- 複製時は見積番号・発行日・有効期限を新規作成用の値に差し替える。
- 税率と単価のフォーム表示から不要な小数点以下を消す。
- controller test と全体テストで確認する。

## 2026-09-17 Ruby dependency security update

- GitHub Actions の `scan_ruby` で検出された bundler-audit の脆弱性警告を解消する。
- advisory の修正版へ `Gemfile.lock` を更新する。
- bundler-audit、brakeman、rubocop、全体テストで確認する。

## 2026-09-30 json 3.x によるトップページ 500 修正

- セッション cookie 付きリクエストで `ActiveSupport::JSON.decode` が `ArgumentError` になる問題を直す。
- `json` を 2.x 系に固定し、flash 付きリダイレクト後の表示を回帰テストで確認する。
