# Work Plan

## 2026-07-01 勘定科目ロック解除

- 年度繰越が成功したら、勘定科目マスタの編集ロックを解除する。
- 既存本番データ向けに、一括解除できる Rake task を追加する。
- サービス単体テストと全体テストで確認する。

## 2026-07-01 科目別入力の金額ラベル改善

- 現行の符号入力仕様は維持する。
- `費用` ラベルを `入出金額` に変更し、正負の意味を tooltip で補足する。
- 全体テストで確認する。

## 2026-07-01 無効な取込ルール検出と勘定科目一覧UI調整

- 科目表に存在しない科目コードを参照する `ImportRule` をCSV取込画面で検出する。
- 無効な取込ルールを一括削除できるようにする。
- 取込時は存在しない科目・ロック中科目を指すルールを自動マッチ対象から外す。
- 勘定科目一覧の行アクションボタンのサイズを揃える。
- 全体テストで確認する。

## 2026-07-01 科目別入力の期間フィルタ

- 科目別入力に月単位の表示期間フィルタを追加する。
- 詳細画面から更新・削除した後も科目別入力へ戻る条件を維持する。
- 表示期間のUIは月だけを選ぶ形式にする。
- 貸借残高は表示期間でリセットせず、年度内の通し残高を表示する。
- 月選択の幅を短くし、フィルタ行が1行に収まりやすくする。
- controller test と全体テストで確認する。

## 2026-07-30 請求書備考欄の入力改善

- 請求書フォームの備考欄を請求情報セクションへ移動する。
- 備考欄には振込先・支払条件などを入力できるよう placeholder を追加する。
- 新規請求書作成時は前月請求書の備考を初期値として引き継ぐ。
- controller test と全体テストで確認する。
