# Handoff

## 2026-07-01 勘定科目ロック解除

- 年度繰越成功時に `accounts.is_lock` は全件 `false` になる。
- 既存本番データの解除は `bin/rails accounts:unlock_all` を実行する。
- `accounts:unlock_all` は対象件数を標準出力に表示するだけで、ロック済み以外の勘定科目は変更しない。

## 2026-07-01 科目別入力の金額ラベル改善

- 科目別入力の金額欄は、選択科目から見た増減額のまま。
- 正の金額は残高増、負の金額は残高減として登録される。
- 銀行科目では入金を正、出金を負で入力する。

## 2026-07-01 無効な取込ルール検出と勘定科目一覧UI調整

- CSV取込画面に、科目表に存在しない科目コードを参照する自動取込ルールが表示される。
- 表示された無効ルールはCSV取込画面のボタンで一括削除できる。
- 取込時の自動マッチは有効かつ未ロックの科目コードを持つルールだけを使う。
- 勘定科目一覧の行アクションボタンは `account-row-action` で高さ・最小幅を揃えている。

## 2026-07-01 科目別入力の期間フィルタ

- 科目別入力は `from_month` / `to_month` クエリで月単位に絞り込める。
- 月指定は現在の会計年度内だけ有効。
- 科目別入力から詳細編集へ渡す戻り先には、摘要・表示期間・アンカーが含まれる。
